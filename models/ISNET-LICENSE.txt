IS-Net general-use weights (models/isnet-w8.onnx)

Source model: isnet-general-use from DIS (Highly Accurate Dichotomous Image Segmentation)
  Code and weights: https://github.com/xuebinqin/DIS  (code under Apache License 2.0)
  ONNX file used: https://github.com/danielgatis/rembg/releases/download/v0.0.0/isnet-general-use.onnx
  sha256 of the source ONNX: 60920e99c45464f2ba57... (first 20 hex digits)

Modification: convolution weights were re-stored as per-channel 8-bit integers with
DequantizeLinear nodes (activations unchanged) to reduce the file from 179 MB to 47 MB.
On the test photos the output masks matched the original model within 0.02% mean difference.
